# 本地网页工作台

```powershell
bun install --frozen-lockfile
bun run dev
```

打开 http://127.0.0.1:4173 。一个 Bun 进程在启动时调用 Vite 构建 React 页面，再同时提供静态资源与转换 API；不需要另开前端或后端进程。关闭终端或 Ctrl+C 停止。修改网页源代码后重启即可重新构建；当前版本没有 HMR。

## 使用

1. 选择本地示例，或上传一个模型及其贴图。ZIP/文件夹必须只有一个模型入口；保留贴图目录结构。直接上传 GLB/VRM 也可以。
2. 在源模型里旋转、缩放、查看无光照/线框；点击模型可识别材质。取消材质勾选立即隐藏，并在下一次转换时移除。每行「只看」可独立观察该材质，再点「还原」或「恢复全部」退出；独看不会改变导出勾选。源模型保留初始姿态。
3. 选择静态或六部位人形，调整面数比例、误差、高度与朝向。人形还可调整肩部、手臂，并在高级配置粘贴 boneMap/materialRules JSON。
4. 点击生成。拖动手臂外展、肩部外移、朝向或高度，会自动切换到「姿势预览」，在原始骨骼与权重上更新，不经过减面、图集或打包。源模型与姿势预览共用已加载的模型；减面修改仍需生成后才能查看最终几何。非 VRM 人形需要明确骨骼映射，本地角色示例自动载入对应 profile。
5. 切换源模型/转换结果，单独查看身体部位，检查最终 128×128 图集和报告里的「各区域实际像素分配」，再下载 mcpack 或 PNG。参数修改会标记上次结果，避免把旧包当成当前设置。

## 范围

- 转换复用正式模块；紧凑图集默认按世界表面面积 × 材质权重分配目标矩形面积，保留至少 3×3 的采样尺寸；打包、边距和像素取整会影响实际比例。负数/跨边界 UV 按 repeat/mirror/clamp 采样其连续使用区域，不再因此拷贝整张源图。内部遮挡面仍会计入面积，不代表完整可见性分析；样本 B色块仍需视觉验收。
- 材质筛选是人工选择，`表情` 快捷按钮只供对照，不会自动判定所有模型的隐藏材质。
- 没有 UV 手绘、图集区域拖拽、玩家动作模拟或游戏安装功能。材质列表右侧现在支持相对像素权重，范围 0–20，默认 1；调整后重新生成。
- Three.js 预览使用实际导出几何和贴图，仍不能替代 Minecraft 渲染与动作验收。
- 本地示例只在源文件存在时显示；样本 B当前优先使用同目录诊断 GLB 缓存以缩短导入耗时。该缓存没有 PMX 原始来源语义，示例用于本地环境对照。
- 文件不上传云端。上传文件留在忽略的 `.cache/web-uploads/`；会话与结果保存在内存，重启后失效。最多保留最近四个模型、八个生成结果，旧会话自动释放。
- 只监听回环地址，变更接口检查同源与 Host；上传相对路径检查目录穿越。单次上传/解压内容限制 256 MB、2000 个文件。

## 面数、误差与性能

- 工作台只保留「调整预览」与「转换结果」两个标签。调整预览统一处理材质、姿势与朝向；右下角「按住看原始」临时还原姿势和朝向，松开恢复，保持当前高度、材质筛选和视角不变。支持鼠标、触摸以及空格/回车按住对照；失焦时自动结束对照。减面与像素权重仍需转换后查看结果。

- 网页面数提示以最终三角面（含双面）计数。建议参考样本 B轻量版 35,122 面，见 `pmx-model-tests.md`；测试确认 Shino 为 52,106 面，见 `windows-client-test.md`。因此约 3–5 万面不提示超量；仅超过 52,106 面时提醒超出已验收样本参考范围、需实机确认，不宣称无法加载或引擎上限。样本 B 203,145 面重版有加载困难反馈，但原因未确认。估算与实际输出均使用此规则。

- 比例下方显示「目标约 N 面」：按当前勾选材质、双面输出和保留比例估算。人形减面会扣除完全透明的壳层。误差约束、清理、部位分组会影响实际面数；上次实际面数另行显示。
- 「形状变化容限」收进高级减面设置。默认 0.03；调小更保形但可能减不到目标，调大更容易减面但可能破坏轮廓。该值相对 Meshoptimizer 的 primitive 尺度，不是模型必然变形的百分比。
- 转换状态显示阶段和已用时，报告记录总用时及人形各阶段耗时；完全相同参数会复用仍在内存中的结果。
- 人形六部位现一次导出，贴图按图复用解码。相同样本 B样本本地测量约 28 秒 → 8.3 秒（排除表情、ratio=.2、maxError=.03；不含导入），不是所有模型或机器的保证。
- 样本 A的旧 UV 包围框相交合并会把稀疏岛连成大矩形；现在只在合并增加的包围空白不超过 10% 时合并，并有限调整矩形长宽以更好打包。同配置对照包间空白约 17.2% → 3.7%，实际非透明 UV 覆盖约 45.5% → 46.1%。UV 岛内部仍有未用区域，不能把 96% 矩形分配率当成 96% 有效纹理。
- 本次按测试要求未打开浏览器或执行网页操作。姿势、估算、导出、UV 采样使用代码测试和本地模型检查；交互与游戏效果由用户手动验收。


## 视角、布局与输入调整

- 切换单材质观察或姿势不自动聚焦，相机方向、位置和观察中心保持；需要重新居中时点击「全景」。
- 独看状态保留在材质行的按钮中，不再在列表上方插入「恢复全部」提示。
- 桌面布局限制在屏幕高度内，材质列表利用左栏剩余空间滚动，报告和设置区独立滚动。
- 网页加载示例时肩部外移默认 0；CLI profile 源文件不变。
- 权重允许 0，可先清空、输入小数，再失焦或按 Enter 提交。0 不会移除材质，只使用最低采样预算；需要移除请取消勾选。
