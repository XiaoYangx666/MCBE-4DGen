# 第三阶段：稀疏 UV 岛拆分实验

> 代码：`src/atlas-core/plan.ts`（`splitSparse` 选项，默认关闭）
> 运行：`node scripts/research/atlas/run-sparse.ts`
> 数据：`data/stage3-sparse.md`

## 1. 方案

| 方案 | 说明 |
|---|---|
| `v2` | 当前预算 + production 合并，不拆分 |
| `strict` | 更严格的合并阈值（增长 ≤5%、覆盖保留 ≥90%），不拆分（不改变几何拓扑） |
| `split4` | v2 + 对覆盖率 <50% 的岛按三角面重心中位数递归二分，最多 4 块 |
| `split8` | 同上，覆盖率 <60%，最多 8 块（三角形数 ≥8） |
| `split8cov` | split8 + 按实际采样 UV 面积计算需求 |

切分算法沿**较长 UV 轴的中位数**递归切割，因此对斜向条带这样的形状会切成
若干短段，而不是用均匀网格（网格对斜条带无效：每个格子里的条带仍然斜跨）。

在三角面层面切分不需要复制顶点；桌面端按顶点写 UV，切分后同一顶点可能属于
两个图表，需要复制。实验用真实模型的逐角顶点 id 精确统计复制量。

## 2. 结果

完整表见 `data/stage3-sparse.md`。关键行：

### 2.1 病理稀疏岛（合成 `sparse-island`，UV 盒 1×1、三角面覆盖 3.8%）

| 方案 | 岛数 | content | UV 覆盖 | 矩形内 UV | 误差 | 边缘误差 |
|---|---|---|---|---|---|---|
| v2 | 1 | 96.9% | 3.8% | 3.9% | 0.1350 | 0.1290 |
| split4 | 4 | 86.6% | **11.9%** | 13.7% | **0.1185** | **0.1063** |

- 有效 UV 像素 618 → 1 950（**3.1×**），误差下降 12%；
- 代价：content 从 96.9% 降到 86.6%（多出 3 个矩形与 gutter）。
  因为该场景只有一个材质，回收的空间无人使用，留成空白；
  在多材质场景中这部分会分给其他材质。

### 2.2 真实模型

| 模型 | 方案 | 岛数 | content | UV 覆盖 | 误差 | 边缘误差 | 规划 ms | 复制顶点 |
|---|---|---|---|---|---|---|---|---|
| shino | v2 | 43 | 84.3% | 58.7% | 0.0587 | 0.0584 | 70 | 0 |
| shino | split4 | 57 | 81.5% | 56.8% | 0.0591 | 0.0589 | 92 | 0 |
| shino | split8 | 88 | 79.7% | 55.6% | 0.0612 | 0.0611 | 205 | 0 |
| nana | v2 | 73 | 79.6% | 51.8% | 0.0443 | 0.0444 | 264 | 0 |
| nana | split4 | 102 | 75.6% | 48.5% | 0.0448 | 0.0450 | 298 | 355 |
| nana | split8 | 136 | 72.5% | 47.1% | 0.0434 | 0.0435 | 402 | 797 |
| furina | v2 | 81 | 78.3% | 34.8% | 0.0773 | 0.0761 | 162 | 0 |
| furina | split4 | 113 | 73.5% | 33.4% | 0.0784 | 0.0773 | 246 | 343 |
| furina | split8 | 212 | 64.6% | 29.4% | 0.0812 | 0.0799 | 560 | 935 |

**结论：在真实模型上，拆分是净损失。**

- 岛数增加 30%～160%，每个新岛都要 gutter，`content` 下降 3～14 个百分点；
- UV 覆盖下降（shino −3.1pt、nana −4.7pt、furina −5.4pt）；
- 误差在 2/3 模型上升（furina +5%），边缘误差同步上升（更碎的矩形边界）；
- 桌面端需要复制 343～935 个顶点（0.6%～3.7%），转换时间增加 1.4～3.5 倍；
- `strict` 合并（不切分）同样降低 content（59%～61%）；
  它的误差略低，但空间利用率太差，不作为候选。

### 2.3 为什么拆分在真实模型上失败

1. **正常 UV 岛的覆盖率并不低**：真实模型的岛覆盖率中位数在 65%～70%，
   拆分只在覆盖率很低的岛上有收益；阈值触发后，大量正常岛也被切开。
2. **gutter 成本随岛数线性增长**：128² 下每个岛至少 2px gutter，
   岛数从 81 增到 212 时，gutter 吃掉 10% 以上的图集。
3. **装箱碎片化**：更多、更小的矩形更难填满，`content` 与 UV 覆盖同时下降。
4. **顶点复制**：桌面端需要复制切缝顶点，增加导出几何与转换成本。
5. **误差没有变好**：切分后每个 piece 的矩形更小，虽然 bbox 浪费少了，
   但 gutter 与装箱损失抵消了收益；边缘误差反而上升。

## 3. 正确性

- 切分只在三角面层面重新分配图表，每个图表仍使用仿射 UV→矩形映射，
  源纹理采样点不变；误差没有出现异常跳变（最大 +5%），说明采样语义正确。
- `sparse-island` 的边缘误差从 0.1290 降到 0.1063，没有接缝/串色迹象。
- 没有改动 repeat/mirror/clamp、alpha、UV 越界路径；`wrap-modes` 场景
  在所有方案下数值完全一致。
- 顶点复制只影响导出拓扑，不影响采样；本轮未在桌面适配器中启用，
  只统计了成本。

## 4. 决策

**保留 `splitSparse` 作为实验选项，默认关闭，不集成到生产流程。**

理由：

- 收益只出现在病理稀疏岛（合成场景 3.1× 有效像素），
  而真实模型的常规 UV 布局会普遍退化；
- 自动判断「哪个岛值得切」需要额外启发式，容易误伤；
- 顶点复制与 gutter 成本在 128² 下不可忽略；
- 现有 v2 预算已经能通过「覆盖率感知需求」在不切分的情况下
  把稀疏岛的浪费转移给其他材质（v2 的 C 方案），风险更低。

如果未来要重新考虑，应先实现**按岛覆盖率选择性触发**（只切覆盖率 <10%
且三角形数足够的岛），并在更多真实模型上验证；本轮数据不支持默认启用。
