# 模型编辑工作区：模型 / 纹理 / 导出

同一份编辑会话现在有三个固定工作区。切换只改变布局，不重新导入模型，也不重置材质权重、部件选择、转换参数或当前结果。

## 布局

- **模型**：左侧部件筛选/选择/删除与材质保留，中间 3D 预览，右侧转换参数。这里不常驻清晰度滑杆、图集分区或纹理预算统计。
- **纹理**：左侧纯材质列表（搜索、筛选、排序、含未使用开关，点击选中并隔离），中间通栏 3D 预览，右侧上半是图集（缩放、点区域选材质），下半是环形占用图（中心显示已用比例，点环上色块定位材质）和一行固定的密度调节（滑杆 + 数值 + 只看 + 恢复）。调节器常驻，选中材质只替换内容，不弹窗也不撑开布局。移动端把预览、列表、检查器改为上下排列。
- **导出**：中间结果预览，右侧当前配置、预览/最终状态、过期提示、生成按钮与图集/转换报告。结果诊断不再使用阻断式弹窗。

工作区标签只显示步骤名和一句用途说明，不再挂部件数、材质数或结果状态角标；只有结果过期时在「导出」上留一个提示点。

## 职责边界

- 模型与纹理工作区只负责编辑和预览，不生成皮肤包、也不提供保存入口；参数变化后自动重算预览，用户停在当前页面，不会被带到别的步骤。
- 导出是唯一能生成最终皮肤包、保存到皮肤包和下载 ZIP 的地方。生成完成后停留在导出页，主按钮变成「保存皮肤…」。
- 工作区之间的切换只由顶部标签完成，任何生成或打包动作都不会自动跳转页面。

## 选择联动

材质、部件和区域都使用稳定标识。点击材质会高亮图集区域并隔离模型中的对应材质；点击图集区域会定位材质；点击 3D 表面会按射线命中材质。共享图集矩形、重叠表面或重复名称产生多个候选时，界面会要求明确选择，不会默认取第一个。

## 预览与导出

- 模型和纹理工作区的参数变化都会以防抖 + latest-wins 队列重新计算纹理预算、图集和预览几何；预览只更新当前页面，不切换工作区。
- 浏览器端会缓存减面后的几何，权重变化不会重复减面。预览模式跳过最终 ZIP 组装。
- 导出工作区在配置未变化时直接复用预览的图集和几何生成皮肤包；配置变化时明确标记结果过期并要求重新生成。
- 服务端 `/api/convert` 支持 `preview: true`，只返回纹理、几何和报告；`POST /api/job/:id/finalize` 用同一份预览结果打包。旧任务不会覆盖新任务。

## 验证

```sh
npm run check
npm test
npm run test:studio
```

`tests/webapp-preview-finalize.test.ts` 验证预览结果可以原样打包；`scripts/checks/check-studio.ts` 覆盖预览任务不可下载、finalize 后 ZIP 可下载的完整流程。
