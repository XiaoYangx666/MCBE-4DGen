# 模型编辑工作区：模型 / 纹理 / 导出

同一份编辑会话现在有三个固定工作区。切换只改变布局，不重新导入模型，也不重置材质权重、部件选择、转换参数或当前结果。

## 布局

- **模型**：左侧部件筛选/选择/删除与材质保留，中间 3D 预览，右侧转换参数。这里不常驻清晰度滑杆、图集分区或纹理预算统计。
- **纹理**：左侧材质搜索/筛选/清晰度调节器和紧凑关联部件，中间 3D 预览，右侧常驻图集诊断。桌面端面板可拖动调整宽度、收起或最大化预览；移动端用「材质 / 3D 模型 / 图集」切换主视图。
- **导出**：中间结果预览，右侧当前配置、预览/最终状态、过期提示、下载与图集/转换报告。结果诊断不再使用阻断式弹窗。

## 选择联动

材质、部件和区域都使用稳定标识。点击材质会高亮图集区域并隔离模型中的对应材质；点击图集区域会定位材质；点击 3D 表面会按射线命中材质。共享图集矩形、重叠表面或重复名称产生多个候选时，界面会要求明确选择，不会默认取第一个。

## 预览与导出

- 纹理调整只更新编辑配置；随后以防抖 + latest-wins 队列重新计算纹理预算、图集和预览几何。
- 浏览器端会缓存减面后的几何，权重变化不会重复减面。预览模式跳过最终 ZIP 组装。
- 导出工作区在配置未变化时直接复用预览的图集和几何生成皮肤包；配置变化时明确标记结果过期并要求重新生成。
- 服务端 `/api/convert` 支持 `preview: true`，只返回纹理、几何和报告；`POST /api/job/:id/finalize` 用同一份预览结果打包。旧任务不会覆盖新任务。

## 验证

```sh
npm run check
npm test
npm run test:studio
```

`tests/webapp-preview-finalize.test.ts` 验证预览结果可以原样打包；`scripts/checks/check-studio.ts` 覆盖预览任务不可下载、finalize 后 ZIP 可下载的完整流程。
